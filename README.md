## Codestruktur

Die importierten Daten befinden sich entsprechend der vorgegebenen Struktur im Ordner *data*\
Die Skrikpte Aufgabe1.py und Aufgabe2.py ziehen Skripte aus *projects* zur Ausführung hinzu.\
Aufgabe1.py und Aufgabe2.py erstellen mit rerun_appl=True neue Modelle als pickle-Objekte in *models*. Bei rerun_appl=False werden diese Objekte aus models geladen für die weitere Ausführung.\
Die Ergebnisse der Aufgaben liegen nach der Ausführung der Skripte als pdf-Dateien in *outputs*\ 
Bei Bedarf können diese Dateien mithilfe von pdf_fusion.py in eine Datei fusioniert werden.
